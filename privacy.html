Privacy

The short version

Your files are processed on your own device by WebAssembly engines; they are never uploaded; there is no account.

What needs the network, and when

The site itself and its engines (Pyodide, qpdf, pdf.js, tesseract.js) load from cdn.jsdelivr.net on first use. OCR additionally downloads language data and needs a connection while recognizing. Heavy engines (pdf2docx, pdfplumber, PyMuPDF) download once, on demand, with the size shown first. After download, engines are cached and tools work offline.

What to check yourself

DevTools network tab shows engine downloads on first use and no file uploads ever. DevTools > Application > Cache Storage shows what the service worker stored. The full source is at github.com/kckckc23/patram (AGPL-3.0).

Hosting

The site is served by Vercel, which processes standard web server logs (IP address, browser) as any host does, and loads Vercel Web Analytics (anonymous page-view counts, no cookies). No ads, no third-party trackers, no file content leaves the device.
